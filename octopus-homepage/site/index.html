  1. 安装桌面版

    选择适合你电脑的安装包，按安装说明启动应用。

  2. 配置模型

    在设置中填写所用模型服务的 API Key。

  3. 选择工作文件夹

    打开你要工作的文件夹，从一个问题开始。
