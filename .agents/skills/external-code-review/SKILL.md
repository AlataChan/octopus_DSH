# 外部代码审查

用户点名 Codex 时调用 `desktop_review_codex`；点名 WorkBuddy 或 CodeBuddy 时调用 `desktop_review_codebuddy`。两者都被点名时分别调用。在任务里写明当前工作目录下要看的文件、用户问题和所需证据。向外部工具描述目标和验收条件，让它自行选择其 harness 提供的只读工具。主会话仅负责委派时，这项限制只适用于主会话；不要指定子工具必须名为 read。每次委派独立运行，最终答复须注明由哪个工具给出意见。

用户询问可用性时，省略 prompt 调用对应工具，检查当前用户的 CLI 和登录状态。委派前工具也会执行该检查。两种 CLI 各自独立。向用户转达缺少安装、登录或网络连接的具体提示。登录、网络、超时和权限错误均表示该次审查未完成。不要自行读取文件后冒充外部工具的结果。
